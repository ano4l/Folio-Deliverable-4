## Application features

- **Documents:** upload and organise files, review processing, read extracted pages and search source text.
- **AI assistance:** ask document questions, inspect citations and practise with generated quizzes and explanations.
- **Study Space:** organise courses, upload lecture material, save notes and review revision cards.
- **Planning:** inspect document-linked tasks and calendar deadlines.
- **Account controls:** inspect security settings and local activity.
- **Administration:** inspect account, session and aggregate AI-activity metadata; private documents, prompts and answers are not exposed in the admin demonstration.
